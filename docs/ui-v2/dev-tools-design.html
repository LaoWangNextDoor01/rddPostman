1. 入口与快捷键

  • 侧栏第 4 个图标：icons.Code
  • 快捷键切换：Ctrl / ⌘ + 4
  • 状态栏右下角 Tools 点击直达
  • Ctrl / ⌘ + K 全局搜索直达任意工具

2. 多标签协同体验

  • 点击工具在右侧开独立 tool:{id} Tab
  • 与 HTTP 请求 Tab、环境 Tab 自由并存
  • 切回集合树时已开工具 Tab 保持状态
  • 同一工具重复点击直接聚焦，不重复开页

3. 色彩与密度规范

  • 严格复用 theme/v2 语义 Token
  • 主内容 #FFFFFF / #1E1E1E
  • 侧栏与 Tab 栏 #F9F9F9 / #191919
  • 强调蓝 #336FFF，控件统一 26–30px

4. 可扩展性预留

  • 工具注册表按分组配置，新增零侵入
  • 二期可平滑加：正则测试、JSON Diff
  • 可加：YAML↔JSON、Cron 解析、颜色转换
  • 后续可支持从响应体右键“发送到 JSON 工具”
